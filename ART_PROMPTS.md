# Arena art prompts

Generated with the built-in ImageGen tool as transparent PNG assets for this project.

## Dinosaur

> Use case: stylized-concept. Asset type: full-body game fighter cutout for a child's dinosaur-versus-knights browser game. Create one original dinosaur character: a young Tyrannosaurus-like dinosaur with believable anatomy and natural proportions, olive and forest green textured scales, subtle lighter underbelly, amber eyes, strong legs and claws, long tail extending behind toward the left. Three-quarter side view, facing RIGHT, grounded upright pose, full body visible including feet and tail. Style: polished semi-realistic fantasy illustration with detailed texture and dimensional lighting; much less cartoonish than a flat vector mascot, while still friendly enough for a six-year-old. Transparent background with clean edges, no scenery, no text, no logo, no crown, no blood, no wounds, no threatening snarl. Match the visual realism level of a companion medieval knight game character.

Saved as `dist/assets/arena-dino-realistic.png`.
